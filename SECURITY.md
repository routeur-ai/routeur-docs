# Security policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, email **security@routeur.ai** with:

- a short description of the issue
- the affected page, file, or API surface
- reproduction steps or proof of concept
- any suggested mitigation, if you have one

We will acknowledge receipt as quickly as possible, investigate privately, and
coordinate any fix and disclosure timing with you where appropriate.

## Scope

This repository contains the public documentation content and public OpenAPI
spec for routeur.ai.

Valid reports include, for example:

- documentation that encourages an unsafe integration pattern
- examples that expose sensitive values or unsafe defaults
- accidental publication of information that should not be public

Product runtime vulnerabilities may also be reported to the same address,
even if they are not caused by this repository.
